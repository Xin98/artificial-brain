# ITER-0004 executable specification

The [approved design](../../superpowers/specs/2026-08-21-iter-0004-private-deployment-and-data-portability-design.md) defines the system for this iteration: Portability becomes a new bounded context that reads and writes only through the Todo, Identity, and Reminder modules' public application interfaces — export streams a zip (per-file sha256 tee, manifest last), import stores the validated bundle as bytea, previews by deterministic decision, and confirm re-decides from the same bundle before executing channels → todos → delivery history with Source Identity idempotency where conflicts never overwrite. Private deployment is a configuration switch: `DEPLOYMENT_MODE=private` provisions a fixed admin from `PRIVATE_ADMIN_PHONE` and rejects every other phone with `registration_closed`, reusing the existing two-step code login untouched. Backup/restore are CONFIRM-gated operator scripts, the offline bundle is a `docker save` target, and the smoke gate gains a same-version upgrade drill.

The API surface is the plan's route table: routes 1–26 from ITER-0002/0003 are unchanged except the two login routes, which change behavior only in private mode; routes 27–30 add the portability export, bundle upload, import view, and import confirm. Errors reuse the stable `{code, message, correlationId}` envelope and `X-Correlation-ID`, adding `registration_closed`, `unsupported_schema_version`, `checksum_mismatch`, `bundle_invalid`, `bundle_too_large`, and `import_conflict`. Tooling remains pinned to Go 1.26.5, Node.js 24.18.0, and pnpm 11.19.0 with zero new Go modules and zero new web dependencies; the schema advances from version 7 to 8 through the append-only migration `008_portability.sql` owned solely by `backend/cmd/migrate`; API and Worker keep the equality schema gate. Health routes and the system-health contract are unchanged.

Acceptance criteria are copied in [brief.md](brief.md). The delivery steps are in the [implementation plan](../../superpowers/plans/2026-08-21-iter-0004-private-deployment-and-data-portability.md).
