# ITER-0005 executable specification

The [approved design](../../superpowers/specs/2026-09-27-iter-0005-conversation-sessions-design.md) defines the system for this iteration: the Conversation module's `ModelPort` becomes `Complete`, returning one envelope `{"schemaVersion":"1","reply":…,"proposal":{…}|null}` per turn; `ValidateModelTurn` guards the envelope while the v1 `ValidateProposal` stays untouched as the inner choke point; unknown/non-intent turns become the new `chat` kind instead of `unsupported`; invalid envelopes or invalid proposals fail closed to `unsupported`. Every turn persists a user row and an assistant row (model reply or deterministic Chinese summary) against a session — auto-created from the first message when `sessionId` is absent, ownership-checked when present. Migration 010 adds `conversation.sessions` and a nullable cascading `conversation.messages.session_id`; the schema pin moves 9→10. The OpenAI-compatible adapter gains the unified prompt and history mapping but is never called from CI; the deterministic adapter keeps every corpus proposal byte-identical and answers unmatched input with the fixed `EchoReplyTemplate` echo.

The API surface is the design's route table: `POST /api/v1/conversation/messages` gains optional `sessionId` and responds with `reply`/`sessionId` and the `chat` kind; the confirmation routes are unchanged; five new routes add session list/create/history/rename/delete under the same cookie auth, error envelope, and strict decoding, with the new stable code `session_not_found` (404). Tooling remains pinned to Go 1.26.5, Node.js 24.18.0, and pnpm 11.19.0 with zero new Go modules and zero new web dependencies; the schema advances from version 9 to 10 through the append-only migration `010_conversation_sessions.sql` owned solely by `backend/cmd/migrate`; API and Worker keep the equality schema gate. Health routes and the system-health contract are unchanged.

Acceptance criteria are copied in [brief.md](brief.md). The delivery steps are in the [implementation plan](../../superpowers/plans/2026-09-27-iter-0005-conversation-sessions.md).
