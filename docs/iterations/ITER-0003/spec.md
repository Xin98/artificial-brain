# ITER-0003 executable specification

The [approved design](../../superpowers/specs/2026-08-19-iter-0003-reliable-reminder-delivery-design.md) defines the system for this iteration: the Reminder module grows from the ITER-0002 scheduling seam into a full delivery hexagon — a `ReminderDelivery` aggregate with a five-state machine created atomically with the plan (one row per requested channel), River-backed scheduling with an insert-only API client joining the caller's ambient transaction via `InsertTx` and a River worker as the sole delivery entry point calling the `SendReminder` application command, execution-time suppression with a UNIQUE business idempotency key, retries with business dead letters, an HMAC-SHA256-signed receipt webhook deduplicated by provider message ID, fake/SMTP/Aliyun provider adapters selected by configuration with production fail-closed gating, real four-state dashboard counters with a delivery record list, and a deterministic-SQL JSON ops endpoint.

The API surface is the plan's route table: routes 1–21 from ITER-0002 are unchanged except the dashboard summary (row 22), which gains `reminderSucceeded`/`reminderSuppressed` and real `reminderRetrying`/`reminderFailed`; rows 23–26 add the reminder list, the ops endpoint, the receipt webhook, and the double-gated dev outbox. Errors reuse the stable `{code, message, correlationId}` envelope and `X-Correlation-ID`, adding one new stable code `invalid_signature`. Tooling remains pinned to Go 1.26.5, Node.js 24.18.0, and pnpm 11.19.0; the only new Go dependencies are `riverqueue/river` and `riverqueue/riverpgxv5` (ADR-0002), with zero new web dependencies. The schema advances from version 5 to 7 through append-only migrations 006–007 (River's official v1 SQL inlined into the tern sequence) owned solely by `backend/cmd/migrate`; API and Worker keep the equality schema gate. Health routes and the system-health contract are unchanged.

Acceptance criteria are copied in [brief.md](brief.md). The delivery steps are in the [implementation plan](../../superpowers/plans/2026-08-19-iter-0003-reliable-reminder-delivery.md).
